# 参数化与迁移

原包的目标IP和接入参数为空。Python 3工具仅生成新副本，不修改网络、不下载程序、不存储凭据。

运行形式（将尖括号内容换成自己的真实参数；不要原样粘贴）：

```text
python scripts/materialize.py --exit-ip <购买的公网出口IP> --upstream-host <控制台入口主机> --upstream-port <控制台入口端口> --protocol <http或https或socks5> --check-url <HTTPS出口检测URL> --output <新的配置副本目录>
```

入口主机不包含http://、用户名、密码或端口。原包不预设具体供应商入口端口。输出目录必须不存在，且不能在原技能目录内。工具拒绝非法/非公网目标IP、含脚本字符的主机名、越界端口及覆盖既有目录。

工具会统一填入出口断言、上游域名与端口、DNS引导域名、Node出口检查及目标JSON；.template文件变成其原始文件名。PS1保存UTF8 BOM以兼容Windows PowerShell5。不会自动校正历史Windows路径、SID、Node版本或应用安装位置，执行配置前必须由agent按实际机器适配。

生成目录的parameters-filled.json记录本次选择，networkConfigured=false表示仅生成了文件，尚未配置或验证网络。之后在该目录执行恢复流程；不要重新对原包做未填参数的审计。

这里的“任意IP”指用户自己所选提供商账户提供且可达的固定公网出口；并不是可以指定不属于自己的IP，也不保证任意套餐/网站均支持。TLS名称默认使用入口主机，若控制台提供专门名称，部署前按实际端点修改并验证。

密码请在目标电脑安全输入。第三方API需要独立提供商配置；无此需求的路由器项目应标记不适用，不为完成检查虚构业务配置。

--tls-server-name 可为 HTTPS 指定独立证书名称，默认入口主机；不强制 TLS 1.2 上限。--check-url 必须无凭据并返回 JSON 顶层 ip。检测失败应报告未知，不能当作断网或出口验证通过。IPv6 入口与白名单免密需人工适配；此生成器不自动配置它们。
